# 💰 Finmente

Sistema de controle financeiro pessoal desenvolvido para auxiliar no gerenciamento de receitas, despesas e metas financeiras.

## 🚀 Funcionalidades

* Login e cadastro de usuários
* Controle de receitas e despesas
* Metas financeiras
* Alertas
* Humor financeiro

## 🛠️ Tecnologias

* Java
* Android Studio
* MySQL
* JDBC
